### Алгоритм

1. **Начало**
2. Ввод данных: `A` — число световых лет (вводит пользователь).
3. Вычислить количество астрономических единиц:
   - `lightYear` = `A` * 63241.077 (1 световой год ≈ 63241.077 астрономической единицы)
4. Вывести результат
5. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>
#define _CRT_SECURE_NO_WARNINGS
#define A 63241.077
void main() {
	setlocale(LC_ALL, "RUS");
	int lightYear;
	float result;
	puts("Введите число световых лет");
	scanf("%d", &lightYear);
	result = A * lightYear;
	printf("%d световых лет %.2f в астрономических единицах", lightYear, result);
```
